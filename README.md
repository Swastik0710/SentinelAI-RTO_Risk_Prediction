# SentinelAI - RTO Risk Prediction

A Machine Learning project that predicts Return-To-Origin (RTO) risk for e-commerce orders using a Random Forest Classifier.

## Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit

## Features
- Real-time RTO prediction
- Probability score
- Feature importance visualization
- Interactive Streamlit web app
